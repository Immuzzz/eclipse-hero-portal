## ✨ Core Technical Highlights & Innovation

### 1. 🤖 Deeply Responsive In-Character Neural Comms Engine (`src/chat.js`)
* **In-Between Question Interception (Mid-Intake Q&A):** If a citizen asks questions at *any* stage during emergency intake (*"Who are you?"*, *"Why do you need my age?"*, *"Where are you dropping from?"*, *"Why do you need my email?"*, *"What weapons do you fight with?"*), the engine **never breaks character** or corrupts data. It answers in authentic hero voice and appends a natural conversational bridge resuming intake.
* **Human Name & Title Parsing:** Extracts clean citizen names from phrasing such as *"My name is Maya Chen"*, *"I'm Dr. Thorne"*, or *"Call me Kenji"*.
* **Forgiving Skip Support:** Recognizes *"skip"*, *"prefer not to say"*, or *"no email"*, seamlessly calibrating baseline civilian telemetry without validation barriers.
* **Extensive Superhero Knowledge Base:** Covers speed (0.94c, 4.5s ETA), suit cybernetics, physical vulnerability/pain, daily life (spicy tonkotsu ramen in Neo-Tokyo, 90-min REM sleep cycles), tactical survival advice, and humor.
* **Dual Dispatch System:** Automatically generates an encrypted Incident Dossier with unique ID (`INC-KEI-XXXX`), transmitting alerts to Developer HQ (`shieldxshield7@gmail.com`) AND sending confirmation receipts with shelter coordinates directly to the citizen's email.

### 2. ⚡ Dynamic Random Rift Simulator & Deploy-and-Fix Intercept (`src/simulator.js`)
* **Random Rift Generation:** Clicking **`[ ⚡ DETECT RANDOM RIFT ]`** calculates randomized surface coordinates, generates dynamic jagged SVG fracture paths, sounds breach klaxons (`sound.playRiftSpawn()`), and degrades crust stability to warning levels.
* **4-Phase Deploy & Suture Sequence:**
  1. *Phase 1 (Target Acquisition):* 0.94c re-entry vector line drawn to breach epicentre.
  2. *Phase 2 (Kinetic Strike):* Relativistic blade slash audio (`playBladeSlash()`), fullscreen impact flash, and canvas blitz.
  3. *Phase 3 (Spatial Suture):* Celestial healing chime (`sound.playRiftSealed()`), cyan/golden energy seal, and expanding shockwave ring.
  4. *Phase 4 (Recovery):* Crust stability and defense readouts smoothly count back up to **100.00% SECURE**.

### 3. 🛡️ High-Tech Sector Preloader & Network Lag Shield (`src/loader.js`)
* Multi-page cyber preloader displaying sector numbers, destination briefings, and animated progress counters.
* Seamless navigation interceptor that eliminates blank screen flashes and compensates for simulated network latency.

### 4. 🎵 Procedural Web Audio Engine (`src/audio.js`)
* 100% code-synthesized audio using Web Audio API oscillators and gain envelopes (zero external audio asset dependencies).
* Procedural sound FX: Mode transition sonic booms, relativistic blade slashes, dimensional rift alarms, celestial suture chimes, and tactical UI feedback.

## 🚀 How to Run Locally

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
* `npm` or `yarn`

### 1. Clone the Repository
```bash
git clone https://github.com/Immuzzz/eclipse-hero-portal.git
cd eclipse-hero-portal
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables (Optional)
```bash
cp .env.example .env
```
Inside `.env`, configure the developer notification email and optional gateway keys:
```env
DEVELOPER_EMAIL=shieldxshield7@gmail.com
VITE_WEB3FORMS_KEY=your_web3forms_key_here
PORT=5173
```

### 4. Launch Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173/`.

### 5. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in `dist/`.
