### 2. 🤖 Direct In-Character Conversational Terminal
- **Authentic Hero Persona:** Directly connects visitors in real-time dialogue with Dr. Kaelen Mercer.
- **Automated Telemetry Collection (FSM):** Guides the visitor through an urgent intake sequence collecting:
  1. **Full Name**
  2. **Age & Civilian Category**
  3. **Sector / Geolocation Coordinates**
  4. **Secure Communication Channel (Email)**
  5. **Emergency Grievance / Anomaly Report**
- **Laser-Swept Civilian Dossier:** Generates a real-time HUD dispatch card summarizing all victim parameters as they are provided.
- **Free-Chat Mode:** Unlocks after grievance submission, allowing users to ask ECLIPSE about his origins, physics principles, or mission protocol.

### 3. 📬 Automated Incident Email Dispatch Pipeline
- Automatically triggers upon grievance submission to notify the developer and emergency response coordinator.
- **Recipient Target:** Developer's direct inbox (`shieldxshield7@gmail.com`).
- **Multi-Gateway Redundancy:**
  - **Primary:** FormSubmit asynchronous AJAX transmission with full civilian telemetry payload.
  - **Secondary:** Web3Forms API gateway for guaranteed delivery without third-party popup redirects.
  - **Local Development:** Integrated Vite Express-compatible incident email dispatcher middleware.

## 🚀 How to Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- `npm` or `yarn`

### 1. Clone the Repository
```bash
git clone https://github.com/Immuzzz/eclipse-hero-portal.git
cd eclipse-hero-portal
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables (Optional)
Copy the example environment template:
```bash
cp .env.example .env
```
Inside `.env`, verify or configure the target developer email and gateway keys:
```env
DEVELOPER_EMAIL=shieldxshield7@gmail.com
VITE_WEB3FORMS_KEY=your_web3forms_key_here
PORT=5173
```

### 4. Launch Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173/`.

### 5. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
